# 存放模型转换中间状态的目录
这个目录可以看到模型被解包出来的json配置文件，可以根据配置文件进行模型动作和行为的设置，对于分析和后面的动作设置很有帮助。

新增模型按 `<角色>/<模型名>/<模型名>.json` 和同名 `.resx.json` 存放，纹理位于模型目录内的资源子目录。正式文件名、菜单和角色动作配置的对应关系见 `config/model-catalog.json`。

2026-10-02 的素材比较、去重决定和浏览器验证记录见 [导入记录](../docs/model-import-2026-10-02/README.md)。临时解包和完整截图目录 `.comparison/` 不纳入 Git。
